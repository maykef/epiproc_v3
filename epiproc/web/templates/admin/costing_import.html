What the import does

  • Reads per product row: name (B), EAN (C), pcs per tray / UPT (J), per-pallet layout (K), box height (L) and the in-box on-pallet price (N). The CC price (M) is ignored.
  • Creates or updates one product per row, matched by EAN — else by exact name. Selling/retail prices set in the calculator are never overwritten.
  • Computes a draft costing for every row with a UPT, a price and a matching box type. Rows that can't be costed are flagged for attention — nothing is finalised automatically.
  • Shared rates (transport, labour, margins) come from costing defaults & menus, not from the sheet.
